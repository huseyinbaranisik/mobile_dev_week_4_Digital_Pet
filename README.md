## 🇬🇧 English

> **Course:** Mobile App Development · Week 4 assignment

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Memo.png" width="26" align="center"> About the Project
A fun digital pet app built with React Native and Expo. Users can feed their pet, play with it and follow its growth.

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Activities/Sparkles.png" width="26" align="center"> Features
- **Splash screen:** Custom animated launch screen.
- **Pet interaction:** Feeding, playing and sleeping mechanics.
- **Stat tracking:** Real-time hunger, happiness and energy levels.
- **Level system:** Earn experience points to level up and unlock achievements.
- **Settings:** Sound on/off and notification preferences.

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Travel%20and%20places/Rocket.png" width="26" align="center"> Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/huseyinbaranisik/mobile_dev_week_4_Digital_Pet.git
   ```
2. Go to the project folder:
   ```bash
   cd mobile_dev_week_4_Digital_Pet
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the app:
   ```bash
   npx expo start
   ```

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Hammer%20and%20Wrench.png" width="26" align="center"> Tech Stack
- **React Native** — mobile app framework
- **Expo** — development toolkit
- **JavaScript** — programming language

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Mobile%20Phone.png" width="26" align="center"> Download the APK
A testable APK is available on the [Releases](https://github.com/huseyinbaranisik/mobile_dev_week_4_Digital_Pet/releases) page. A user-experience report (`kullanıcı_deneyimi.pdf`) and a demo video are also in the repo.

> **[📺 Watch the app demo video](https://youtube.com/shorts/kv0gGIet9II)**

## 🇹🇷 Türkçe
